# GalGen（Galgame Generator）

基于 Python 的双端 Galgame 制作工具：**管理器端**负责角色、场景、剧情、章节、结局、函数、资产的编辑与项目管理，支持**一键生成游戏端 `.exe`**（含 AI 语音生成）。

双端统一采用 **pywebview + Web 前端** 架构：界面用 HTML/CSS/JS 编写，由 pywebview 以原生 WebView 承载，Python 后端负责数据读写与文件操作。

## 功能特性

### 管理器端（manager）
- **项目文件（.gg）**：JSON 编码（UTF-8 无 BOM、LF 换行、snake_case，格式 v2），格式规范见 `project.md`；旧版文件打开后保存自动迁移
- **角色**：变量（好感度等）、常量、简介、性格、**立绘列表式管理**（从资产选择/上传/删除/重命名/设默认）、**显示名列表**（化名揭示）
- **场景 / 章节 / 结局**：场景背景、章节拖动排序、章节分支条件、结局类型与 CG
- **剧情**：一条剧情 = 一个对话单元（**文本 / 选项 / 音效 / 视频**），列表多选/拖拽/复制/批量删除，新建弹出居中类型选择框，分支树状图、一键导出 txt
- **音效**：播放方式（播放 / 播放并等待 / 循环直到指定剧情）、淡入淡出时长、倍速、**互斥**（有语音/视频时暂停）
- **视频**：沉浸播放（隐藏对话区），可点击跳过，播完自动下一条
- **函数**：可复用动作库（跳转 / 解锁结局·隐藏剧情·隐藏CG / 修改变量），剧情引用多个、选项指向单个
- **资产**：背景/场景/立绘/CG/界面/背景音乐/音效/语音/视频/图标分类，图片·音频·视频内嵌预览，**支持重命名**（磁盘文件同步改名），**真实引用次数分析**（含引用位置），多选批量删除
- **AI 语音**：edge-tts 免费合成，角色→声线映射（含旁白），批量生成、进度日志
- **生成**：校验 → 一键生成 `.exe`（单文件 / 目录），**自动递增大版本**（可开关）、exe 图标、进度条与构建日志
- **设置**：项目信息、**版本号三段编辑**（总/大/小）、保存自动递增小版本（可开关）、系统字体下拉（中文前置）、exe 图标选择
- **快捷键**：Ctrl+N 新建内容 / Ctrl+Shift+N 新建项目 / Ctrl+S 保存 / Ctrl+Shift+S 另存为 / Ctrl+Z·Ctrl+Y 撤销重做 / Ctrl+F
- **界面**：顶部 SVG 图标按钮、功能区宽度拖拽调整（持久化 + 多页面联动）、启动自动最大化

### 游戏端（runtime）
- **基础阅读**：打字机效果、点击/回车翻页、自动阅读、快进已读文本、速度与字号调节
- **顺序推进**：一条剧情播完自动播放下一条（按章节 + 剧情顺序），直到章节分支/结局或手动存档
- **分支选项**：鼠标/数字键/方向键选择，选项指向**函数**（跳转/解锁/修改变量），章节分支条件判定
- **音效**：播放/等待/循环播放，淡入淡出、倍速、互斥暂停与恢复
- **视频**：沉浸播放（隐藏对话区），可跳过，播完自动下一条
- **多章节推进**：上一章结束后自动进入下一章，好感度门槛决定是否进入后续章节
- **存档 / 读档**：3 个槽位 + 快速存读（F5/F8）、存档缩略图、返回上一个选择点
- **鉴赏模式**：画廊（CG 解锁/灰锁）、音乐室（音频试听）、剧本回想（已读对话）、隐藏剧情
- **设置**：文字速度、自动阅读等待、BGM/SE/语音音量、全屏切换、重置进度
- **结局统计**：已收集结局列表与未收集提示

## 技术栈

| 模块 | 方案 |
| --- | --- |
| 界面框架 | pywebview（原生 WebView 承载 HTML/CSS/JS） |
| 前端实现 | 原生 HTML/CSS/JS + Alpine.js（表单联动）+ SortableJS（拖拽排序），零构建工具 |
| 数据解析 | 标准库 `json` |
| AI 语音 | edge-tts（微软 Edge 在线 TTS，免费、无需 API Key） |
| 打包工具 | PyInstaller（`--noconsole`，无控制台窗口，支持自定义 exe 图标） |

## 目录结构

```
galgen/
├── project.md               # 开发计划与 .gg 格式规范
├── requirements.txt
├── manager/                 # 管理器端
│   ├── main.py              # pywebview 入口（启动自动最大化）
│   ├── web/                 # 前端（index.html / css / js）+ api.py 后端桥接
│   │   └── js/vendor/       # 第三方库（alpine / sortable）
│   ├── core/                # .gg 读写、校验、导出、配置、资产、AI、字体、引用分析
│   └── builder/             # 一键生成 .exe 构建器
├── runtime/                 # 游戏端运行时
│   ├── main.py / release_main.py
│   ├── stage.py             # 装配：.gg + 资产 → 可运行 Web 目录
│   ├── game_api.py          # 窗口控制（退出/全屏）
│   └── web/                 # 游戏前端
└── tests/                   # 单元测试（60 项）
```

## 安装与使用

```bash
pip install -r requirements.txt
```

**管理器端**

```bash
python -m manager
```

**游戏端（开发态）**

```bash
python -m runtime 项目.gg
# 省略参数则自动打开最近在管理器中使用的项目
```

**一键生成 .exe**：在管理器「生成」页选择产物形态（单文件/目录）后点击「一键生成 .exe」，产物输出到项目 `dist/` 目录。

## 测试

```bash
python -m unittest discover -s tests
```
