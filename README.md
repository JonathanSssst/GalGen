# GalGen（Galgame Generator）

基于 Python 的双端 Galgame 制作工具：**管理器端**负责角色、场景、剧情、章节、结局、资产的编辑与项目管理，支持**一键生成游戏端 `.exe`**。

双端统一采用 **pywebview + Web 前端** 架构：界面用 HTML/CSS/JS 编写，由 pywebview 以原生 WebView 承载，Python 后端负责数据读写与文件操作。

## 功能特性

### 管理器端（manager）
- **项目文件（.gg）**：JSON 编码（UTF-8 无 BOM、LF 换行、snake_case），格式规范见 `project.md`
- **角色**：变量（好感度等）、常量（年龄/生日）、简介、性格、表情 → 立绘映射
- **场景 / 章节 / 结局**：场景背景、章节拖动排序、章节分支条件、结局类型与 CG
- **剧情编辑器**：对话列表增删改排序复制、文本/选项两种类型、选项绑定效果/跳转（支持跨剧情）/解锁/结局、分支树状图、一键导出 txt
- **资产**：图片/音频/视频分类管理，上传、预览、筛选排序、标签、分类迁移
- **生成**：校验项目 → 一键生成 `.exe`（单文件 / 目录，含进度条与构建日志）

### 游戏端（runtime）
- **基础阅读**：打字机效果、点击/回车翻页、自动阅读、快进已读文本、速度与字号调节
- **分支选项**：鼠标/数字键/方向键选择，好感度等变量修改，跨剧情分支，章节分支条件判定
- **多章节推进**：上一章剧情结束后自动进入下一章，好感度门槛决定是否进入后续章节
- **存档 / 读档**：3 个槽位 + 快速存读（F5/F8）、存档缩略图、返回上一个选择点
- **鉴赏模式**：画廊（CG 解锁/灰锁）、音乐室（BGM 试听）、剧本回想（已读对话）、隐藏剧情
- **设置**：文字速度、自动阅读等待、BGM/SE/语音音量、全屏切换、重置进度
- **结局统计**：已收集结局列表与未收集提示
- 启动自动全屏，最小窗口 800×600

## 技术栈

| 模块 | 方案 |
| --- | --- |
| 界面框架 | pywebview（原生 WebView 承载 HTML/CSS/JS） |
| 前端实现 | 原生 HTML/CSS/JS，零构建工具 |
| 数据解析 | 标准库 `json` |
| 打包工具 | PyInstaller（`--noconsole`，无控制台窗口） |

## 目录结构

```
galgen/
├── project.md               # 开发计划与 .gg 格式规范
├── requirements.txt
├── manager/                 # 管理器端
│   ├── main.py              # pywebview 入口
│   ├── web/                 # 前端（index.html / css / js）+ api.py 后端桥接
│   ├── core/                # .gg 读写、校验、导出、资产文件、配置
│   └── builder/             # 一键生成 .exe 构建器
├── runtime/                 # 游戏端运行时
│   ├── main.py / release_main.py
│   ├── stage.py             # 装配：.gg + 资产 → 可运行 Web 目录
│   ├── game_api.py          # 窗口控制（退出/全屏）
│   └── web/                 # 游戏前端
└── tests/                   # 单元测试（50 项）
```

## 安装与使用

```bash
pip install -r requirements.txt
```

**管理器端**

```bash
python -m manager
```

**游戏端（开发态）**

```bash
python -m runtime 项目.gg
# 省略参数则自动打开最近在管理器中使用的项目
```

**一键生成 .exe**：在管理器「生成」页选择产物形态（单文件/目录）后点击「一键生成 .exe」，产物输出到项目 `dist/` 目录。

## 测试

```bash
python -m unittest discover -s tests
```
